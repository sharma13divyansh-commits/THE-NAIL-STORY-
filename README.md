# The Nail Story by Madhu — Premium Luxury Website

A luxury, feminine, and modern responsive website created for **The Nail Story by Madhu**, a premier nail art studio and beauty salon in Uttam Nagar, New Delhi.

![The Nail Story Logo](public/assets/logo.png)

## ✨ Brand Palette & Aesthetic
- **Nude Pink:** `#F5E6E8`
- **Soft Blush:** `#F8EFF0`
- **Rose Gold:** `#B76E79`
- **Champagne:** `#E8C9B8`
- **Cream White:** `#FFF9F5`
- **Dark Brown:** `#352629`

## 🌟 Features
- **Editorial Sticky Navigation:** Logo, opening hours announcement, mobile drawer menu, and direct CTA.
- **Hero Section:** Highlighting studio artistry with bespoke nail extension visuals and core brand pillars.
- **About Us Section:** The studio philosophy, experience, and hygiene commitments.
- **Services Menu:** 22 detailed services across 3 categories (Nail Services, Manicure & Pedicure, Beauty & Relaxation) with instant WhatsApp inquiry buttons.
- **Interactive Nail Art Gallery:** Filterable portfolio featuring real client work with full-screen Lightbox view.
- **Why Choose Us:** 4 feature pillars (Creative Nail Art, Professional Service, Affordable Luxury, Welcoming Ambience).
- **Client Testimonials:** 7 authentic customer reviews with quote styling and decorative ratings.
- **Social Media:** Direct links to official Instagram (`@the_nail_story_by_madhu`) and YouTube with visual grid.
- **Direct WhatsApp Appointment Booking:** Form validation that generates pre-filled WhatsApp messages to `+91 9355205419`.
- **Location & Hours:** Embedded Google Maps, transit directions, and Monday-Sunday opening timetable.
- **Floating Quick Contact:** Instant WhatsApp chat & phone call button.

## 🛠️ Tech Stack
- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS + PostCSS
- **Icons:** Lucide React + Bespoke SVGs
- **Typography:** Playfair Display, Poppins, Montserrat

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
